## Jarayon

### Ishlatilgan texnologiyalar

- Semantik HTML5 strukturasi (`<main>`, `<article>`)
- CSS3 maxsus xususiyatlari (Custom Properties)
- Flexbox (elementlarni markazlashtirish uchun)
- Mobil-birinchi (Mobile-first) yondashuvi

### Nimalarni o'rgandim

Ushbu loyiha davomida semantik HTML teglari va CSS Flexbox yordamida kartochkani sahifa markaziga to'g'ri joylashtirishni mustahkamladim.

### Kelgusi rejalar

Kelgusi loyihalarda murakkabroq CSS Grid maketlari bilan ishlash, mobil moslashuvchanlikni yanada mukammallashtirish va Accessibility standartlariga to'liq rioya qilishni davom ettiraman.
